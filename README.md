# NaviPro 3D Enterprise

Навигатор нового поколения с 3D-экструзией зданий, дорожной разметкой по ГОСТ Р 51256 и B2B-режимами для такси, доставки и ресторанов.

## Сборка APK на GitHub
1. Загрузите содержимое архива в корень нового репозитория на GitHub.
2. Перейдите во вкладку **Actions** -> запустите workflow **Build NaviPro 3D Enterprise APK**.
3. Скачайте готовый `NaviPro3D-Enterprise-debug.apk` из раздела **Artifacts**.
